# 🤝 Contributing to ChitinAI

Thank you for your interest in contributing to **ChitinAI**! We welcome bug reports, feature requests, and pull requests from the community.

---

## 🛠️ How to Contribute

### 1. Fork and Clone
1. **Fork** the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone [https://github.com/YOUR-USERNAME/ChitinAI.git](https://github.com/YOUR-USERNAME/ChitinAI.git)
   cd ChitinAI
### 2. Set Up Environment
​Create a virtual environment and install dependencies:
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
pip install pytest
### 3. Create a Feature Branch
​Create a branch for your feature or bugfix:
git checkout -b feature/your-feature-name
